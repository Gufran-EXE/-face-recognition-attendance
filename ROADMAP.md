## 📚 Tech Stack

### Backend
- **Framework:** FastAPI
- **Database:** PostgreSQL (prod), SQLite (dev)
- **Cache:** Redis
- **ML:** MediaPipe, OpenCV, face_recognition
- **Auth:** JWT
- **Testing:** pytest

### Frontend
- **Framework:** React 18+ with Vite
- **State:** Zustand
- **UI:** Tailwind CSS
- **Real-time:** Socket.IO
- **Testing:** Jest, Cypress

### DevOps
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Monitoring:** Prometheus, Grafana
- **IaC:** Docker Compose, Kubernetes
